# NS Web

Base para la futura web del proyecto NS.

Objetivo inicial:

- login de usuarios
- panel para medicos u operadores
- creacion de tareas
- consulta de estados y resultados
- conexion con la app/agente local de escritorio cuando una tarea necesite ejecutar PAMI en Windows

El stack todavia no esta fijado. Esta carpeta queda separada para que despues el deploy apunte solo a `web/`.
